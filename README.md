# Movie Watch List (React + styled-components)

![alt text](image.png)

**Live Demo:** https://a2rp.github.io/movie-watch-list/

A lightweight, frontend-only Movie Watch List to save films you **want to watch**, are **watching**, and have **watched** — with a built-in ⭐ **rating system**. Dark-theme friendly and fully **LocalStorage** powered.

## Features

-   Add movies with **title**, year, status (To Watch / Watching / Watched)
-   ⭐ **Rating** 0–5 with keyboard support (←/→)
-   **Quick actions**: change status & rating inline
-   Edit fields: **rating, poster URL (with fallback), notes**
-   **Search** (title/year), **Filter** (status), **Sort** (Newest, Title, Year, Rating, Status)
-   **Clear all “Watched”** (confirm modal)
-   Data persists in **LocalStorage** (refresh-safe)

## Local Install

```bash
git clone https://github.com/a2rp/movie-watch-list.git
cd movie-watch-list
npm i
npm run dev
```
